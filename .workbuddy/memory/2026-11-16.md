## 追加：白屏修复（16:51 反馈）

**现象**：用户本地打开白屏。
**根因**：构建产物原本用绝对路径 `/assets/...` + Vite 默认 base `/`。用户**直接双击 dist/index.html**（file:// 协议）时，浏览器禁止 ES module 从 file:// 加载任何 JS → 白屏（无报错），这是所有 Vite 构建应用的通用限制，不是代码问题。
**修复**：
1. `vite.config.ts`：加 `base: './'`，移除已无用的 `/api` proxy。
2. 源码硬编码绝对路径全部改相对：App.tsx / main.tsx / Welcome.tsx 的 `/favicon.svg`→`./favicon.svg`，Welcome `/art/pasture-concept.webp`→`./art/...`，Cottage.tsx `/models/cottage.glb`→`./models/...`，progression.css 两张 atlas 图 `url("/art/...")`→`url("../art/...")` + 复制图到 `src/art/`（让 Vite 构建时内联打包，dev/prod 都正常）。
3. package.json 加 `start` 脚本：`vite preview --host 0.0.0.0 --port 4378`（本地看成品一条命令）。
4. DEPLOY-SINGLE.md 补"不要双击 dist/index.html""本地看用 npm run start / npx serve / python -m http.server"。
**验证**：构建后 dist/index.html 全部 `./assets/...` 相对引用；headless Chrome 实测 python http.server 起 dist → 首页渲染/进3D世界/学习屋全部通过，0 控制台错误。
**经验沉淀**：Vite 建的应用交付给用户"本地看"必须给启动命令，不能指望双击 html；file:// 白屏是浏览器对 ES module 的硬限制，无解（除非全量打包单文件），直接引导用本地静态服务器。
